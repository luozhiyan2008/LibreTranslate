# 校区中俄专业术语库说明

## 功能简介
本仓库在 LibreTranslate 基础上新增"深北莫校区中俄专业术语库"功能，
保证校园高频专业词汇在中俄互译时使用统一、规范的译法。

## 实现方式
- `libretranslate/school_terms.py`：术语库模块。翻译前对术语做占位符保护，
  翻译后回填标准译法；若机翻结果已包含术语词干，也会自动统一为标准译法（双保险）。
- `school_terms.json`：术语表，格式为 `"中文术语": "俄语译法"`。

## 如何添加新术语
在 `school_terms.json` 中按上述格式追加，保存后重启服务生效。

## 测试示例
输入：高等数学、矩阵和数据结构是必修课
输出：Высшая математика, матрица и структура данных являются обязательными предметами
